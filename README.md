# Introduction to Programming with Python

Teaching material for learners with no prior background in computing. The course introduces programming fundamentals with Python through executable notebooks, exercises, and video lessons.

The goal is to develop algorithmic reasoning, code-reading skills, and the autonomy to build small programs.

# Content

The main learning path is in [`aulas_algoritmos_programacao/`](aulas_algoritmos_programacao/):

1. [`01_intro_sintaxe_python.ipynb`](aulas_algoritmos_programacao/01_intro_sintaxe_python.ipynb) — syntax, expressions, and first commands;
2. [`02_intro_logica_operacoes_matematicas.ipynb`](aulas_algoritmos_programacao/02_intro_logica_operacoes_matematicas.ipynb) — operators, precedence, and logic;
3. [`03_tipos_variaveis.ipynb`](aulas_algoritmos_programacao/03_tipos_variaveis.ipynb) — data types and variables;
4. [`04_condicionais_if_else.ipynb`](aulas_algoritmos_programacao/04_condicionais_if_else.ipynb) — conditional structures;
5. [`05_loops_for_while.ipynb`](aulas_algoritmos_programacao/05_loops_for_while.ipynb) — `for` and `while` loops;
6. [`06_funcoes.ipynb`](aulas_algoritmos_programacao/06_funcoes.ipynb) — functions, parameters, return values, and scope;
7. [`07_recursao.ipynb`](aulas_algoritmos_programacao/07_recursao.ipynb) — recursion and base cases;
8. [`08_python_lambdas.ipynb`](aulas_algoritmos_programacao/08_python_lambdas.ipynb) — lambda functions;
9. [`09_funcoes_aninhadas.ipynb`](aulas_algoritmos_programacao/09_funcoes_aninhadas.ipynb) — nested functions and *closures*;
10. [`10_exercitando.ipynb`](aulas_algoritmos_programacao/10_exercitando.ipynb) — integrative exercises;
11. [`11_listas_calculos_com_termos.ipynb`](aulas_algoritmos_programacao/11_listas_calculos_com_termos.ipynb) — lists and calculations over collections;
12. [`12_dicionarios.ipynb`](aulas_algoritmos_programacao/12_dicionarios.ipynb) — dictionaries and key–value structures.

The detailed catalog is available in [CONTENTS.md](CONTENTS.md). The recommended learning sequence is in [COURSE.md](COURSE.md).
