# Course Catalog

## Core Curriculum

1. [`01_intro_sintaxe_python.ipynb`](aulas_algoritmos_programacao/01_intro_sintaxe_python.ipynb) — syntax, expressions, and first commands.
2. [`02_intro_logica_operacoes_matematicas.ipynb`](aulas_algoritmos_programacao/02_intro_logica_operacoes_matematicas.ipynb) — operators, precedence, and logic.
3. [`03_tipos_variaveis.ipynb`](aulas_algoritmos_programacao/03_tipos_variaveis.ipynb) — numbers, strings, and data structures.
4. [`04_condicionais_if_else.ipynb`](aulas_algoritmos_programacao/04_condicionais_if_else.ipynb) — `if`, `elif`, and `else`.
5. [`05_loops_for_while.ipynb`](aulas_algoritmos_programacao/05_loops_for_while.ipynb) — iteration and flow control.
6. [`06_funcoes.ipynb`](aulas_algoritmos_programacao/06_funcoes.ipynb) — parameters, return values, and scope.
7. [`10_exercitando.ipynb`](aulas_algoritmos_programacao/10_exercitando.ipynb) — integrative exercises.
8. [`11_listas_calculos_com_termos.ipynb`](aulas_algoritmos_programacao/11_listas_calculos_com_termos.ipynb) — iteration and calculations over lists.
9. [`12_dicionarios.ipynb`](aulas_algoritmos_programacao/12_dicionarios.ipynb) — key–value structures.

## Intermediate Topics

- [`07_recursao.ipynb`](aulas_algoritmos_programacao/07_recursao.ipynb) — recursive functions and base cases.
- [`08_python_lambdas.ipynb`](aulas_algoritmos_programacao/08_python_lambdas.ipynb) — anonymous functions.
- [`09_funcoes_aninhadas.ipynb`](aulas_algoritmos_programacao/09_funcoes_aninhadas.ipynb) — inner functions and *closures*.

The classification above distinguishes the foundations required for beginners from topics that can be studied later. The physical order of the files has been preserved to avoid breaking existing links. See [COURSE.md](COURSE.md) for the recommended sequence and lesson quality criteria.
